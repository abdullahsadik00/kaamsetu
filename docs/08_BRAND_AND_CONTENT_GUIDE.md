# 08 — KaamSetu Brand and Interface Content Guide

## 1. Working brand

**Name:** KaamSetu  
**Hindi:** कामसेतु  
**Pronunciation:** Kaam-Setu

**Meaning:**
- Kaam = work.
- Setu = bridge.

The name represents a bridge between the business owner, field teams, customers and service work.

**Working tagline:** काम आसान। हिसाब आसान। कारोबार आसान।

English interpretation: Work made easier. Accounts made easier. Business made easier.

## 2. Positioning

KaamSetu is simple AC service business software for small service companies in India.

It helps owners manage jobs, teams, customers, bills and payments while helping field technicians focus on the actual service.

## 3. Brand personality

- Helpful.
- Practical.
- Trustworthy.
- Familiar.
- Clear.
- Efficient.
- Not overly technical.

Avoid language that makes the product sound like a large enterprise ERP.

## 4. Naming caveat

KaamSetu is a working product name. Before public use:
- Search Indian trademark databases.
- Check domain names.
- Check Google Play naming conflicts.
- Check company/business name conflicts.
- Obtain appropriate legal advice.

Do not assume availability from the fact that the name sounds distinctive.

## 5. Interface writing principles

- Use short sentences.
- Prefer common words.
- One instruction at a time.
- Avoid accounting/engineering jargon.
- Avoid abbreviations.
- Explain errors with a recovery action.
- Use consistent words for the same action.

## 6. Preferred UI labels

| Prefer | Avoid |
|---|---|
| My Work | Assigned Work Orders |
| Start Work | Initiate Job |
| Finish Work | Submit Service Report |
| Customer | Client Entity |
| AC Details | Equipment Metadata |
| Bill | Receivable Document |
| Received | Payment Allocation |
| Remaining | Outstanding Receivable |
| Needs another visit | Follow-up workflow required |
| Saved | Local persistence completed |
| Sending | Synchronization in progress |
| Sent | Server synchronization successful |

## 7. Sample messages

Success:
- Job saved.
- Work completed.
- Bill created.
- Payment recorded.
- Photo added.

Errors:
- Couldn't save. Please try again.
- Internet is unavailable. Your work is saved on this phone.
- This job was updated elsewhere. Ask the owner to review it.
- Payment could not be recorded. Check your connection and try again.

## 8. Language support

Initial options:
- English.
- Hindi.
- Marathi.

Allow each employee to choose a preferred interface language. Do not assume every employee wants the same language.

Use localization keys and test the interface on actual Android devices.

## 9. Visual identity direction

Suggested starting direction:
- Deep teal/blue-green as primary.
- Warm saffron accent used sparingly.
- Warm off-white background.
- Dark charcoal text.
- Clear green/amber/red status colors.
- Simple geometric bridge/connection motif if a logo is developed.

Do not finalize a logo or color palette before checking readability and contrast in the actual app.
